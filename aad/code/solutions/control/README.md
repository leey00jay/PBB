# 제어 파트 — control

**판단 파트가 정한 경로와 목표 속도를 실제 차량 움직임으로 만듭니다.**
카메라에서 차선을 찾거나 차로를 선택하는 일은 인지·판단 파트가 담당합니다.

## 담당 파일

| 파일 | 역할 |
|---|---|
| `vehicle_controller.py` | 현재 카메라 모드의 액셀·브레이크·조향 제한과 제어 명령 계산 |
| `pure_pursuit.py` | 경로를 따라갈 조향각 계산, 원본 교재의 PID 제어기 |
| `get_target_point.py` | 경로에서 Pure Pursuit 목표점 선택 |

**액셀 상한과 속도 계산을 수정할 곳은 `vehicle_controller.py`입니다.**
`pure_pursuit.py` 위쪽의 `param_Kp`, `param_Ki`, `param_Kd`는 현재 `--ld` 카메라 모드의 속도 계산에 사용되지 않습니다.

## 현재 동작

- 입력 속도는 m/s, 목표 속도는 km/h입니다. 계산할 때 목표를 3.6으로 나눕니다.
- 비례·적분(PI) 속도 제어를 사용합니다. `max_throttle=0.75`, `speed_kp=0.6`, `speed_ki=0.3`입니다.
- 목표보다 느린 상태가 이어지면 부족한 출력을 적분 보정합니다. 최대 액셀 출력에서는 보정값을 더 쌓지 않습니다.
- 정지 판단, 목표 경로 소실, 목표 속도 0에서는 적분 보정을 초기화합니다. 목표 속도를 낮출 때도 이전 보정값을 초기화합니다.
- 액셀과 브레이크를 동시에 사용하지 않으며, 주행 중 속도 제어의 브레이크 상한은 0.6입니다. 정지 판단의 0.7 및 초기 준비의 1.0 제동은 유지합니다.
- 조향 명령 범위와 시간에 따른 조향 변화량 제한을 유지합니다.
- 판단이 정지를 지시하거나 Pure Pursuit 목표점이 없으면 제동합니다.
- Town10HD 스폰 21의 Audi TT 직선 시험에서 목표 20km/h에 약 19.99km/h로 수렴했습니다. 실제 곡선·교차로에서는 인지/판단 결과에 따라 감속하거나 정지할 수 있습니다.

## 다음 작업

1. HUD의 목표/실제 속도, `throttle / brake`, 판단 상태를 함께 확인합니다.
2. 다른 차량·경사·곡선에서도 속도 수렴과 과속 여부를 확인합니다.
3. 조향 흔들림, 곡선 이탈, 목표 경로가 사라졌을 때의 제동을 검사합니다.

## 속도 수정의 근거

2026-11-11의 녹화 원본 332장을 다시 인식한 결과, 준비 구간 이후 302장 모두
주행 허용 상태였습니다. 정지 판단 대신 액셀 0.4 상한에 계속 걸리는 상황이었습니다.
동일한 Town10 Audi TT의 짧은 직선 비교 시험에서는:

- 기존 비례 제어 + 상한 0.4: 시험 시작 10초 시점 약 9.29km/h.
- 비례 제어 + 상한 0.75: 약 17.27km/h에 머무름.
- PI 제어 + 상한 0.75: 10초 시점 약 19.93km/h, 마지막 1초 평균 약 19.99km/h.

위 시간은 CARLA 시뮬레이션 시간이며 시작 1초의 정지 준비를 포함합니다.
이는 속도 제어의 직선 시험 결과이며 카메라 차선 유지의 모든 상황을 검증한 결과는 아닙니다.

## 전달 형식

`VehicleController.update(plan, speed, dt)` → [ControlCommand](../interfaces.py)

- `speed`: 실제 속도 m/s. `dt`: 시뮬레이션 시간 간격, 초.
- `throttle`, `brake`: 0~1. `steer`: -1~1 범위의 정규화된 명령.
- `target_kmh`, `status`: 제어까지 반영된 최종 목표와 상태. 조향 목표점을 못 찾으면 `NO STEERING TARGET - STOP`으로 보고합니다.
- CARLA에 실제 명령을 보내는 것은 실행 파일의 역할입니다. 제어 계산 자체는 CARLA 없이 시험할 수 있습니다.

## 검사

PBB의 `.venv`를 활성화한 뒤 `aad` 폴더에서:

```bash
python -m unittest code.tests.control.test_vehicle_controller -v
python -m unittest code.tests.control.test_lane_following -v
```

카메라 차선 유지 실행 파일도 300프레임 시험하여 마지막 1초 평균 19.90km/h,
마지막 프레임 19.93km/h를 확인했습니다. 준비 30프레임 이후 정지 판단은 없었습니다.
시험 차량을 제거하고 원래 시뮬레이터 설정을 복구했습니다.
