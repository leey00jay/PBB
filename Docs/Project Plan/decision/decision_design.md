# 판단 모듈 설계 (Decision Module)

## 1. 네 가지 주행 상태 정의

| 상태 | 의미 | 차량 행동 |
|---|---|---|
| NORMAL | 정상 주행이 가능한 상태 | 차선 유지 및 정상 주행 |
| CAUTION | 위험 가능성이 감지된 상태 | 속도 감소 및 주의 주행 |
| DANGER | 충돌 또는 차선 이탈 위험이 높은 상태 | 강한 감속 및 위험 대응 |
| EMERGENCY | 정상 주행을 지속하기 어려운 상태 | 안전 정지 요청 |

## 2. 판단 모듈 입력 (Input)

| 입력값 | 의미 |
|---|---|
| lane_error | 차선 중심에서 벗어난 정도 |
| lane_confidence | 차선 인식 신뢰도 |
| vehicle_speed | 현재 차량 속도 |
| slip_risk | 차량 미끄러짐 위험도 |
| obstacle_distance | 전방 장애물까지 거리 |
| ttc | 충돌 예상 시간 |
| camera_ok | 카메라 정상 작동 여부 |

## 3. 판단 모듈 출력 (Output)

| 출력값 | 의미 |
|---|---|
| driving_state | 현재 주행 상태 |
| target_speed | 목표 주행 속도 |
| brake_request | 감속 및 제동 요청 |
| steering_mode | 조향 제어 방식 |

## 4. 상태 전환 조건

| 조건 | 전환 상태 |
|---|---|
| 정상 주행 조건 충족 | NORMAL |
| 차선 인식 신뢰도 저하 | CAUTION |
| 미끄러짐 위험 증가 | CAUTION 또는 DANGER |
| 충돌 예상 시간 감소 | DANGER |
| 카메라 입력 상실 및 안전 주행 불가능 | EMERGENCY |
| 위험 해소 및 센서 정상 확인 | NORMAL 복귀 검토 |

## 5. 판단 모듈 동작 과정

1. 인지 모듈 및 차량 센서로부터 입력값 수신
2. 차선, 차량 안정성, 충돌 위험, 센서 상태 분석
3. 위험 수준에 따라 주행 상태 결정
4. 목표 속도 및 제어 방침 생성
5. 제어 모듈에 판단 결과 전달

## 6. 향후 구현 계획

- CARLA 환경에서 판단 모듈 구현
- 5개 한계상황 시나리오에 대한 상태 전환 검증
- 상태별 목표 속도 및 제동 조건 설정
- 기준 알고리즘과 개선 알고리즘 비교
- 실험을 통한 상태 전환 임계값 조정

※ 본 문서는 초기 설계안이며, 구체적인 임계값과 상태 전환 우선순위는 추후 CARLA 실험을 통해 확정한다.
