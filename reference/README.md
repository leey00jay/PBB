# 이전 교재와 실습 자료

현재 주행 코드는 루트 src/의 ROS 패키지에 있습니다. 이 폴더는 교재·노트북·이전 실행 방식의 참고 자료입니다.
aad의 인지·판단·제어 파일은 새 패키지로 옮겼으며, 이전 위치에는 import 호환 파일만 있습니다.
이 자료는 ROS 주행의 실행 의존성이 아닙니다. 이전 스크립트의 경로·실행법은 현재 기본 실행과 다를 수 있습니다.
현재 실행: ../start_ros2.sh, 안내: ../docs/ros2_launch.md.
원본 라이선스·저작자는 aad/LICENSE, aad/CONTRIBUTORS.md에 보존합니다.
